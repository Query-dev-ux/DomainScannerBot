## v0.2 — приоритет: пригодность домена для FB-трафика
Google Safe Browsing недостаточно: он не знает про внутренние блокировки Facebook.
Нужны сигналы, которые реально влияют на залив:

- [ ] **Facebook URL status** — проверка, не блокирует ли FB ссылку. Официального API
      нет; варианты: запрос к `https://www.facebook.com/sharer/sharer.php?u=`,
      Graph API `?fields=engagement` (даёт ошибку для забаненных), либо эвристика по
      редиректу на страницу «ссылка нарушает нормы сообщества».
- [ ] **Проверка редиректов/клоаки** — куда реально ведёт домен, отдаётся ли white page.
- [ ] **SSL/TLS** — валидность сертификата, срок, издатель.
- [ ] **Возраст домена** (RDAP/WHOIS) — свежий домен = выше риск бана.
- [ ] Учитывать `Domain.status` из PWA API (код 7 «занят», 11 «ошибка выпуска» и т.д.).

## v0.3 — эксплуатация
